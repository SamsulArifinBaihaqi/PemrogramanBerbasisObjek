## Cakupan Materi Praktikum

- Konsep dasar Object-Oriented Programming (OOP)
- Perbedaan OOP vs Prosedural
- Class, Object, Atribut, dan Method
- Enkapsulasi (Access Modifier)
- Pewarisan (Inheritance)
- Polimorfisme (Overloading & Overriding)
- Abstraksi (Abstract Class & Interface)
- Konstruktor dan Keyword this / super
- Relasi Antar Objek (Agregasi, Komposisi, Asosiasi)
- Penanganan Eksepsi (Exception Handling)
- Java Collections Framework
- GUI (Java Swing / JavaFX)
- Integrasi Database (JDBC)

## Panduan Menjalankan Project

1. Buka Terminal atau Command Prompt di folder project.
2. Arahkan ke direktori file Java yang ingin dijalankan:
   cd Pertemuan2/Tugas
3. Lakukan kompilasi source code:
   javac MainMatkul.java
4. Eksekusi program:
   java MainMatkul
